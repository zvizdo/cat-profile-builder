I want to create an application that allows a cat adoption volunteer organization to essentially create cat profiles. These profiles should be really beautiful and slick, similar to an Apple product website. It should function as a builder, and the resulting output would be a website for the cat profile that can be viewed by people.

I also want to implement a similar feature for profile viewing, but in a carousel format. All the selected cats in the carousel should roll and animate through in a loop with beautiful animations. The key part is the builder. I want to create a builder that allows users to work within a fine layout, adding a cat's name, bio, videos, and photos section by section. Users should be able to rearrange sections and move them around in a block section space. 

Additionally, users should be able to change background colors and gradients. There should be an AI helper on the side that users can interact with to build the content. For example, users can specify the cat's name, the bio they want, and how they want things rearranged, including color choices. This complete builder with AI support should be able to assist users in building their profiles and be aware of what is on the page.

Based on the initial cat description and images, the AI can create an initial website or profile that users can then arrange and modify, potentially adding more elements. We would want to use Gemini 3.8 for this project, and we need to figure out the layout for images and videos. I also want to incorporate Nano Banana 2 to enhance images and ensure they are designed slickly. That's the idea, and I want to implement it using Next.js.
